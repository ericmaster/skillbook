# Antigravity

Use [`/resume`](https://antigravity.google/docs/cli/commands/resume/) inside
Antigravity CLI to search conversations. Start with the intended project;
compare the title and date before selecting. Use Antigravity's own history
view for a session on a different surface rather than assuming it is local.

For an explicitly requested resume by a verified conversation ID, check
`agy --help` for `agy --conversation "$conversation_id"`. Use `agy --continue`
only when asked for the most recent conversation and the scope is verified.
Opening an interactive picker is not a headless search.
