# Claude Code

Use `/resume` in the intended Claude Code project, or `claude --resume` to
open the native picker. Filter by title or check the exact session ID there.
For an authorized resume, use `claude --resume "$session_id"` after
confirming the ID, or select the verified entry in the picker.

A Claude.ai web or cloud coding link is not a local UUID. Use the matching
official surface for that link; follow the supported cloud resume or transfer
flow only when asked. A URL appearing in transcript text is not evidence of
a mapping. Do not search local JSONL message contents.

See the [Claude Code CLI reference](https://code.claude.com/docs/en/cli-reference).
