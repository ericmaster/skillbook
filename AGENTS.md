# Maintaining Skillbook

- Keep each skill in `skills/<name>/SKILL.md` with matching `name` and a
  trigger-specific `description`. Verify it works from its installed directory.
- Add bundled resources only when a skill needs them. Keep examples generic and
  verify redistribution rights for every new file.
- Update the README index when the collection changes. Record pending changes in
  `CHANGELOG.md`; only record a published version after release.
